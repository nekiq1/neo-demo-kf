# KoreaFan Auto — сайт и онлайн-запись

## Запуск локально
1. Установите Node.js 20.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `ADMIN_USERNAME`, `ADMIN_PASSWORD` и параметры выбранного канала уведомлений.
4. Выполните `npm install`, затем `npm run dev`.

## Сборка
`npm run typecheck` и `npm run build`.

## Важно о данных
- Название, телефон, рейтинг и перечень направлений перенесены из публичной карточки KoreaFan Auto в Яндекс Картах.
- В карточке карт не опубликован прайс: цены намеренно указаны как «По запросу», а не выдуманы.
- Длительность записи 60 минут — технический стартовый слот, его нужно согласовать с сервисом в админ-панели.
- Карточка карт не дала однозначный полный адрес и подтверждённый график. Витрина просит уточнять точное место и график по телефону; часы в админке — редактируемая стартовая настройка.
- Фотографии в `public/studio` — временные иллюстрации макета, а не подтверждённые фотографии работ KoreaFan Auto. Замените их на фото сервиса перед публикацией.

## Уведомления
Выберите `NOTIFY_CHANNEL=telegram`, `vk` или `both` и заполните соответствующие переменные окружения. Для Telegram укажите токен бота и chat ID. Для VK — access token и peer ID. Ключи хранятся только на сервере в `.env`.


## Обновления витрины и Railway
- Внизу каждой страницы добавлены ссылки на профиль/записи, юридические документы и защищённый вход администратора.
- На главной странице добавлена компактная карта Яндекс с точкой из ссылки пользователя и подтверждённая ссылка VK.
- Список работ и последовательность изображений сохранены из исходного проекта; файлы находятся в `public/studio/`.
- Добавлена форма добровольной подписки на новости. Подписки записываются в таблицу `newsletter_subscribers`; для постоянного хранения в Railway подключите сервис PostgreSQL и переменную `DATABASE_URL`. В текущей сборке отправка писем подписчикам не настроена — список адресов только сохраняется.
- Админ-вход: `ADMIN_USERNAME` + `ADMIN_PASSWORD`. Старый `ADMIN_PIN` оставлен как резервный режим. Замените значения примера на уникальные секреты и не коммитьте `.env`.
- Конфигурация Railway находится в `railway.toml`; команда запуска — `npm run start`, сборки — `npm ci && npm run build`.
- Страница `/legal` содержит редактируемую основу политики и согласий, а не юридическое заключение. Заполните реальные реквизиты оператора, email для обращений, сроки хранения, подрядчиков и фактические способы обработки до публикации.

## Данные из источников
Карточка Яндекс Карт подтверждает название KoreaFan Auto, телефон +7 (931) 100-77-79, район Ручьи, рейтинг 4,6/12 оценок, VK не подтверждается самой карточкой (ссылка VK найдена в стороннем справочнике). Прайс и полный адрес не подтверждены, поэтому они не выдуманы. Список работ и порядок фотографий оставлены из исходного репозитория.
